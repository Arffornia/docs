What NeoForge 1.21.1 allows

  1. Nothing in Minecraft draws before ModLauncher starts: the first seconds belong to the launcher (splash, then handoff).
  2. A mod jar starts too late; only a separate early-window provider jar named in config/fml.toml replaces the stock screen, with raw OpenGL, no Minecraft classes, fixed 854×480×scale framebuffer, 20 Hz until handoff.
  3. No theming API on 1.21.1 (themes arrived for 1.21.8+): we subclass FML's DisplayWindow and keep NeoForge's handoff and overlay.
  4. fml.toml is per instance and earlyWindowControl=false disables it; later reloads (F3+T) keep the vanilla overlay.
  5. Loading-screen machines are baked sprite frames; real 3D block rendering starts with the title screen.
