# Arffornia

Arffornia is a modded Minecraft server (NeoForge 1.21.1) built around a **progression system
inspired by Satisfactory**: milestones, a Space Elevator and machines that gate a large tech
modpack, so every mod stays worth playing. Players install a custom launcher, sign in with
Microsoft, and join through a proxy; a website handles accounts, the shop, votes and the
progression editor. Everything runs on a Kubernetes homelab managed with GitOps.

## The ecosystem

![The Arffornia ecosystem](assets/ecosystem.light.svg#only-light)
![The Arffornia ecosystem](assets/ecosystem.dark.svg#only-dark)

Every project, by repository: **Play** (what players touch), **Game** (the modded server) and the **Toolkit** we build with, all running on **MaaS**, Minecraft as a Service: the platform that provisions a Minecraft server in a few clicks. The picture is generated by `scripts/ecosystem.py`; add a project to its `PROJECTS` list to update it.
